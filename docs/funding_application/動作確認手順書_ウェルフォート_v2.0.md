## 第 1 章 本書の目的と進め方

### 1.1 目的

本書は、補助金事務局のご担当者が**実際にシステムを操作して動作を確認**いただくための手順書である。

『補助事業要件定義書 v3.0』に記載した機能 ID（F-1 〜 F-20）と、本書の確認項目（No.1 〜 No.58）を 1 対 1 で対応させている（付録参照）。本書の確認項目をすべて実施いただくことで、同要件定義書に記載した機能が実際に稼働していることをご確認いただける。

本事業において発注者は、Web アプリケーション開発（当社）と AI 推論システム（別事業者）をそれぞれ別個に発注している。**本書は、当社が受注した Web アプリケーション開発の範囲を対象とする**（見積書 P2026060010-R2 / 納品書 D2026060010-R2 に対応）。AI 推論システム（健康アドバイスの自動生成エンジン）は本書の対象に含まない（第 5 章）。

### 1.2 確認にかかる時間の目安

| グループ | 確認項目 | 所要時間の目安 |
|---|---|---|
| A. 利用者向け機能 | No.1 〜 No.42（42 項目） | 約 75 分 |
| B. 管理機能（社内向け） | No.43 〜 No.53（11 項目） | 約 30 分 |
| C. 品質・個人情報保護 | No.54 〜 No.58（5 項目） | 約 20 分 |
| **合計** | **58 項目** | **約 125 分** |

A グループのみでも主要機能の確認は可能である。B グループは管理者権限が必要なため、**当社担当者の立会のもと**で実施いただく。

### 1.3 本書の読み方

各確認項目は以下の形式で記載している。

| 列 | 意味 |
|---|---|
| **No.** | 確認項目番号 |
| **機能 ID** | 『補助事業要件定義書 v3.0』第 3 章の機能 ID |
| **画面** | 操作する画面 |
| **操作** | 実施いただく操作 |
| **期待される結果** | 操作後に画面上で確認できること |
| **確認** | ご確認後にチェックいただく欄 |

### 1.4 確認対象外の範囲（事前にご承知いただきたい事項）

以下は本書の確認対象に**含まない**。理由は第 4 章・第 5 章に記載する。

| **当社の受注範囲外** | **AI 推論システム（健康アドバイスの自動生成エンジン）** | **発注者が当社とは別に発注した別事業者の担当であり、当社の成果物に含まれないため（第 5 章）** |

### 2.2 確認用アカウントの登録（事前に当社が実施）

本システムは会員制サービスのため、**確認用アカウント**をご用意する。

| 手順 | 実施者 | 内容 |
|---|---|---|
| ① | **事務局** | 動作確認に使用するメールアドレス（Google アカウント推奨）を当社へご連絡 |
| ② | **当社** | 管理画面の「デモ用アカウント管理」から当該メールアドレスを**デモ用アカウント枠**（F-17）へ登録 |
| ③ | **当社** | 登録完了をご連絡 |
| ④ | **事務局** | 下記 2.3 の URL からサインイン |

**デモ用アカウント枠について**: この枠に登録されたアカウントでサインインすると、**動作確認用のダミーデータ**で全画面の動作を確認できる。**実際の顧客データは一切表示されない**ため、個人情報に触れることなく確認いただける。

ダミーデータには以下を用意している。

| 内容 | 件数 |

### 2.4 事前にご承知いただきたい仕様

確認中に「操作できない」と見える箇所があるが、いずれも**意図した仕様**である。

| # | 事象 | 理由 |
|---|---|---|
| 1 | **PC では「カメラで撮影」ボタンが表示されない** | カメラスキャンはスマートフォン専用機能である（PC にカメラが無い環境でエラー画面にならないよう、タッチ操作可能な端末でのみ表示する）。PC では「ファイルをアップロード」をご利用いただく |
| 2 | 検査キット進捗の **ステップ 5・6（検査会社受領／検査完了）を利用者が操作できない** | この 2 ステップは検査会社からの連携情報で自動更新されるため、利用者の自己申告対象外である |
| 3 | AI 問診で**氏名・生年月日・性別を尋ねられない** | 顧客データベースから内部取得して問診結果へ自動付与するため、重複して尋ねない設計である |
| 4 | AI 問診の設問数が回答内容により変動する | **36 設問のうち 11 問が条件分岐**であるため（例: 喫煙しない方には喫煙本数を尋ねない） |
| 5 | スキャンで**送信後すぐに画面を閉じてよい** | 読取処理は送信後にサーバ側で非同期に実行されるため（F-16） |
| 6 | 一度登録した検査原本は**削除できない** | 監査目的で 10 年保管の書込ロックを設定しているため。確認作業ではサンプル検査票をご使用いただく |
