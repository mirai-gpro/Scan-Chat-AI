## 送信前にやること（社内手順）

1. **`https://www.wellfort.co.jp/admin/partner-accounts` を管理者で開く**
2. 「利用者を追加」→ partner = **プリベント** / 表示名 = 例「担当A」
   - **氏名・メールアドレスは入れられません**（`@` を含む値は API が拒否します）。
     「担当A」「担当B」のような識別名にしてください。氏名との対応は社内で持ちます。
3. その行の **「招待コードを発行」** を押す
4. 表示されたコード（`ABCD-EFGH-…` 形式）を**控える**
   - **この 1 回しか表示されません**（DB には sha256 しか入りません）。紛失したら再発行です。
5. 下の本文の `<招待コード>` を差し替えて送信

### 実測にもとづく注意（`partner-auth.ts` / `api/partner/auth/[action].ts`）

| 事実 | 根拠 |
|---|---|
| **招待コードは 1 回限り**（登録に成功すると `used_at` が入り、以後は無効） | `[action].ts:50` / `:195` |
| **有効期限は 7 日** | `partner-auth.ts:39` `INVITE_TTL_SEC` |
| **1 コード＝1 端末**。ご利用になる方・端末ごとに 1 通ずつ必要 | 同上（単回使用のため） |
| ログイン後のセッションは **8 時間**。切れたら生体認証でログインし直し | `partner-auth.ts:35` `SESSION_TTL_SEC` |
| 本人確認は **指紋 / 顔認証 / PIN / セキュリティキー** | 画面の文言（`partner-portal-preview.astro:150`） |

**コードをメール本文に載せたくない場合**は、本文から URL だけを送り、コードは電話や別経路でお伝えください。
登録画面は**手入力でも受け付けます**（URL にコードを付けると自動で入力されるだけです）。

## 件名

【ウェルフォート】専用ポータル パスキー登録のご案内（検査結果PDF のご提出開始にあたって）

## 本文

株式会社プリベント
ご担当者様

平素より大変お世話になっております。株式会社ウェルフォートでございます。

先般ご確認いただきました「データ受け渡し 専用ポータル」につきまして、
**本番運用に向けたパスキー（生体認証）のご登録のご案内**をお送りいたします。
ご登録いただきますと、同じ画面から**検査結果PDF のご提出**を開始いただけます。

■ ① ご登録用URL（お一人・1 台につき 1 回限り有効）

　**https://www.wellfort.co.jp/partner-portal-preview?partner=prevent&register=<招待コード>**

　**有効期限：発行から 7 日間**

■ ② ご登録の手順（30 秒ほどで完了します）

1. 上記 URL を、**ご提出に使われる端末**（PC・スマートフォン）で開いてください。
2. 「この端末を登録」の画面が開き、**招待コードは自動で入力されます**。
   そのまま「**この端末を登録する**」を押してください。
3. 端末の**指紋 / 顔認証 / PIN**（またはセキュリティキー）で本人確認をしていただくと、登録完了です。

**パスワードの設定・ご記憶は不要です。** 弊社がパスワードをお預かりすることもありません。

■ ③ ご登録後のご利用方法

　**https://www.wellfort.co.jp/partner-portal-preview?partner=prevent**

　以後はこの URL をお開きいただき、「**パスキーでログイン**」から
　指紋 / 顔認証 / PIN で入っていただけます（招待コードは不要です）。
　ログインの有効期限は **8 時間**です。切れた場合は、同じ操作で入り直してください。

　メニューは、ご確認いただいたときと同じ 2 つです。

- **問診CSV を取得**（Wellfort → 御社）
- **検査結果PDF を提出**（御社 → Wellfort）… **ご登録後は実際に弊社へ届きます**
  （PDF 形式・1 ファイル 50MB まで。ドラッグ＆ドロップで送信でき、提出済みのファイルは
  「提出状況」に残ります）

■ ④ お願いとご注意

- **①の URL は、ご登録になるご本人だけがお使いください。**
  1 回のご登録で無効になりますので、転送・共有はお控えください。
- **ご利用になる方・端末が複数ある場合**は、**人数ぶん・台数ぶん**の URL をお送りいたします。
  必要な数をお知らせください。
- 有効期限が切れた場合や、URL を紛失された場合は、**再発行**いたしますのでご連絡ください。
- ご登録いただいた端末を変更・追加される場合も、あらためてご案内をお送りいたします。

ご不明な点がございましたら、何なりとお申し付けください。
引き続きどうぞよろしくお願い申し上げます。

## 申し送り

- 本番で**実際に S3 まで届くか**を確かめるには、本番 Vercel の **`LAIF_PORTAL_UPLOAD=on`** と
  AWS S3 の設定が必要です（未設定だとチケット発行が 503 になります）。
  **先方へ送る前に、社内で 1 件通しておく**ことをおすすめします。
- 着弾先は `s3://<bucket>/quarantine/prevent/YYYY/MM/DD/<UUID>.pdf` です
  （元のファイル名はオブジェクトのメタデータに保持されます）。
