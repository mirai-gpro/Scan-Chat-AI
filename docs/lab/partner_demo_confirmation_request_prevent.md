## 本文

::notice
本デモは、パスキーの設定なしでそのままご覧いただけます
がんリスク検査（尿・ALA-PDS）のデータ受け渡しについて、実際の画面と操作の流れをご確認いただけるデモをご用意しました。本番運用では**パスキー（生体認証）によるアクセス管理**を行いますが、**今回は仕様のご確認が目的のため、認証設定は行っておりません。**ダミーデータによる画面確認用で、実データの保存・送信は行われません。
::

## 1. デモ画面URL

::url
https://www.wellfort.co.jp/partner-portal-preview?partner=prevent&review=1
::

::steps
STEP 1 | メニュー
*STEP 2（上り） | 問診CSVを取得 | ダウンロード
*STEP 3（下り） | 検査結果PDFを提出 | アップロード
::caption 画面の上部に、確認用であることをお知らせする帯を表示しております

::note
プリベント様が操作されるのは**専用ポータル画面のみ**です。AWS S3 等の内部保管・後続処理は Wellfort 側で行います。
現在、フォルダ共有リンクをメールでやり取りし、その都度アクセス権をご申請いただいている運用を、**1 つのポータルでの取得・提出に置き換える**ことを想定しております。
::

## 3. 検体との突合に使う番号について

ご要望を踏まえ、**弊社で独自の整理番号を採番することは取りやめ、検査キットに印字されたバーコードNo. をそのまま用いる**ことといたしました。下記の認識で相違ないか、ご確認をお願いいたします。

| # | ご確認事項 |
|---|---|
| (1) | **突合に使う番号＝検査キットに印字されたバーコードNo.**（例：`704000123`）。弊社側での採番は行いません。 |
| (2) | **使用する箇所は 3 つで、すべて同じ番号に統一**いたします。① ポータルの一覧に表示する番号　② 問診CSV に記載する識別番号　③ ファイル名（例：`704000123.csv`）。ファイル名の形式にご希望がございましたらご指示ください。 |
| (3) | **番号の取得方法**は、キットをお受け取りになった時点で、お客様ご自身にスマートフォンで撮影・登録いただきます。 |
| (4) | **生年月日**は貴社の検査要件に合わせて含めます。**氏名・住所・電話番号・メールアドレスは含めません。** |

## 4. 問診CSV 様式のご提供のお願い（今回いちばんお願いしたい点）

::note
デモ画面の「取得」は、**現時点ではダウンロードできない状態**にしてございます。弊社が独自に作成した様式を「これでお渡しします」とご案内して行き違いになることを避けたく、**貴社ご指定の様式を頂戴したうえで実装**したいと考えております。
::

お手数ですが、**記入例を 1 点**（または様式の定義）をご提供いただけますでしょうか。あわせて下記をご教示ください。

| # | ご教示いただきたい事項 |
|---|---|
| (1) | 列名と項目の順序 |
| (2) | ヘッダ行の有無（ある場合は行数） |
| (3) | 文字コード（Shift_JIS / UTF-8・BOM の有無）と改行コード |
| (4) | 日付・時刻の書式（例：`2026/10/13` か `2026-10-13`、時刻の有無） |
| (5) | 選択肢項目の表記（例：性別は「男／女」か「1／2」か） |
| (6) | 空欄（該当なし・未取得）の表し方 |
| (7) | 1 ファイルに 1 名か、複数名をまとめるか |
| (8) | ファイル名の規則 |

また、**ALA のご摂取日時／採尿日時／排尿回数／検体の冷凍保存／採尿前日のお薬・ご飲酒**の各項目につきまして、現在の弊社の問診にはご設問がなく、どこで取得するのが適切か決めかねております。**① 必須か任意か　② いつ時点の情報か　③ 弊社側で取得すべきか、貴社の検体受付でご取得いただいているか**をご教示いただけますでしょうか。

## 5. 検査結果PDF のご提出について

ご提出は、同じポータルの「検査結果PDFを提出」からお願いする想定です（**本番ではパスキー登録後**にご利用いただけます。ドラッグ＆ドロップ・**1 ファイル最大 50MB**）。

**ファイル名にバーコードNo. を含めていただけますと、検体との突合が確実になります。** 貴社で現在お使いのファイル名の規則をご教示ください。
