## 本文

プリベント株式会社
〇〇様

平素より大変お世話になっております。株式会社ウェルフォートの〇〇でございます。

先般ご提案いたしました「データ受け渡し専用ポータル」につきまして、**実際の画面をご用意いたしました**ので、ご確認をお願いいたします。

**お手続きは何も必要ございません。**下記の URL を開いていただくだけで、そのままお試しいただけます。

### ■ 1. ご確認の手順（**お手続きは不要です**）

まずは、**下記の URL を開いていただくだけ**で、そのまま画面と操作をお試しいただけます。
**ID・パスワード・アプリのご用意はいりません。**

　**https://www.wellfort.co.jp/partner-portal-preview?partner=prevent**

操作の流れ：
**「問診CSVを取得」** →（内容をご確認）→ **「検査結果PDFを提出」**（ファイルを選ぶ → 「受付完了」）

> **この段階では、ファイルは実際には送信されません。** 画面の動きをご確認いただくためのものですので、
> 手元の適当なファイルでお試しいただいて差し支えありません。
> 問診CSV も**記入例のサンプル**で、実際のお客様の情報は含まれておりません。

### ■ 1-2. ご了承をいただいたあとのお手続き（パスキー）

上記をご確認いただき、**この方式で進めてよいとご判断いただけましたら**、
本番運用に向けて**パスキー（パスワードのいらない認証）のご登録**をご案内いたします。

- こちらから**招待リンク**（1 回限り有効）をお送りします
- お使いの端末で一度ご登録いただくと、以降は**ログインするだけ**でご利用いただけます
- **顔・指紋のほか、Windows の PIN でもご登録いただけます**（生体認証のない端末でも可）
- 担当者様が複数の場合は**人数分**、端末を追加される場合も**その都度**発行いたします

**順番としては、①まず画面をご確認いただき → ②ご了承後にパスキー、という進め方**を想定しております。
LAiF 様にも同じ手順でご確認いただきました。

### ■ 2. 画面でできること

| | 内容 |
|---|---|
| **問診CSVを取得** | Wellfort → プリベント様。約33項目（`会員ID / 生年月日 / 性別 / 身長 / 体重 / ALA摂取日時 / 採尿日時 / 排尿回数`） |
| **検査結果PDFを提出** | プリベント様 → Wellfort。ドラッグ＆ドロップまたはファイル選択（**1 ファイル 50MB まで**） |

- お客様の識別は**整理番号（仮名ID・`WF-CANCER-…`）**で行います。**氏名・ご住所は含みません。**
- ただし本検査はモデル要件により、**生年月日は含みます**。
- **今回のご確認の段階では、ファイルは実際には送信されません。** 画面の動きのご確認用ですので、
  手元の適当なファイルでお試しいただけます。**パスキーのご登録後から、実際の受け渡しが始まります。**

### ■ 3. 現時点でのお断り

**問診CSVについて、現在ダウンロードいただけるのは記入例のサンプルです。** お客様ごとの実ファイルの配信は準備中で、**それまでは従来どおりの方法でお渡しいたします**。項目・形式のご確認にはサンプルでご判断いただけます。

### ■ 4. ご確認いただきたい点

1. **画面と操作の流れ**にご不明な点・ご要望はございませんか。

3. **検査結果PDF のご提出**の操作に問題はございませんか。
4. この方式で進めてよろしいでしょうか（ご了承いただけましたら、**パスキーのご案内**へ進みます）。
