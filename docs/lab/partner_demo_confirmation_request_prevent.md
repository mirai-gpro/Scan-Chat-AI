## 本文

プリベント株式会社
〇〇様

平素より大変お世話になっております。株式会社ウェルフォートの〇〇でございます。

先般ご提案いたしました「データ受け渡し専用ポータル」につきまして、**実際の画面をご用意いたしました**ので、ご確認をお願いいたします。

### ■ 1. ご確認の手順

本ポータルは、**パスキー（パスワードのいらない認証）でのご利用を前提**としております。恐れ入りますが、**下記の招待リンクからご登録のうえ**、画面をご確認ください。

　**招待リンク：https://www.wellfort.co.jp/partner-portal-preview?partner=prevent&register=〇〇〇〇〇〇**

1. 上記リンクを開く（**登録画面**が表示されます）
2. お使いの端末でパスキーを登録（**顔・指紋のほか、Windows の PIN でもご登録いただけます**）
3. 以降は、同じ端末で**ログインするだけ**でご利用いただけます

> **招待リンクは 1 回限り有効**です。有効期限内にご登録をお願いいたします。
> 複数の担当者様がお使いになる場合は、**人数分を発行**いたしますのでお知らせください。
> 端末を変更・追加される際も、お手数ですが再度ご連絡ください（管理者からの招待でのみ追加できる仕組みです）。

### ■ 2. 画面でできること

| | 内容 |
|---|---|
| **問診CSVを取得** | Wellfort → プリベント様。約33項目（`会員ID / 生年月日 / 性別 / 身長 / 体重 / ALA摂取日時 / 採尿日時 / 排尿回数`） |
| **検査結果PDFを提出** | プリベント様 → Wellfort。ドラッグ＆ドロップまたはファイル選択（**1 ファイル 50MB まで**） |

- お客様の識別は**整理番号（仮名ID・`WF-CANCER-…`）**で行います。**氏名・ご住所は含みません。**
- ただし本検査はモデル要件により、**生年月日は含みます**。
- **結果PDFのご提出は、本番と同じ経路で実際に転送されます**（お預かりしたファイルは隔離領域へ保管いたします）。テストでのご送信も差し支えございません。

### ■ 3. 現時点でのお断り

**問診CSVについて、現在ダウンロードいただけるのは記入例のサンプルです。** お客様ごとの実ファイルの配信は準備中で、**それまでは従来どおりの方法でお渡しいたします**。項目・形式のご確認にはサンプルでご判断いただけます。

### ■ 4. ご確認いただきたい点

1. **パスキーのご登録**に支障はございませんでしたか（端末・ブラウザの制約など）。
2. **問診CSV の項目・形式**に齟齬はございませんか。
3. **検査結果PDF のご提出**の操作に問題はございませんか。
4. 画面と操作の流れについて、ご不明な点・ご要望はございませんか。

### ■ 5. あわせてご教示ください

- **固定グローバルIP**の有無（IP許可制を併用するかの判断に使用いたします）
- **ご利用担当者・通知先メールアドレス**（新しい問診CSV の配置時に自動通知いたします）

ご不明点・ご要望がございましたら、何なりとお申し付けください。
引き続きどうぞよろしくお願い申し上げます。
