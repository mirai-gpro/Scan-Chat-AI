## 3. 検体との突合に使う番号について

ご要望を踏まえ、**弊社で独自の整理番号を採番することは取りやめ、検査キットに印字されたバーコードNo. をそのまま用いる**ことといたしました。下記の認識で相違ないか、ご確認をお願いいたします。

| # | ご確認事項 |
|---|---|
| (1) | **突合に使う番号＝検査キットに印字されたバーコードNo.**（例：`704000123`）。弊社側での採番は行いません。 |
| (2) | **使用する箇所は 3 つで、すべて同じ番号に統一**いたします。① ポータルの一覧に表示する番号　② 問診CSV に記載する識別番号　③ ファイル名（例：`704000123.csv`）。ファイル名の形式にご希望がございましたらご指示ください。 |
| (3) | **番号の取得方法**は、キットをお受け取りになった時点で、お客様ご自身にスマートフォンで撮影・登録いただきます。 |
| (4) | **生年月日**は貴社の検査要件に合わせて含めます。**氏名・住所・電話番号・メールアドレスは含めません。** |

## 4. 問診CSV 様式のご提供のお願い（今回いちばんお願いしたい点）

::note
「取得」から、**問診CSV のサンプル**（33項目・UTF-8［BOM付］・改行 CRLF・ファイル名は**バーコードNo. + .csv**）をダウンロードいただけます。**中身はダミー**です。
**列名・項目順・選択肢の表記は、御社フォームの項目をもとにした弊社の案**でございます。確定した様式ではございませんので、**相違がございましたらご指摘ください**。
::

お手数ですが、**記入例を 1 点**（または様式の定義）をご提供いただけますでしょうか。あわせて下記をご教示ください。

| # | ご教示いただきたい事項 |
|---|---|
| (1) | 列名と項目の順序 |
| (2) | ヘッダ行の有無（ある場合は行数） |
| (3) | 文字コード（Shift_JIS / UTF-8・BOM の有無）と改行コード |
| (4) | 日付・時刻の書式（例：`2026/10/13` か `2026-10-13`、時刻の有無） |
| (5) | 選択肢項目の表記（例：性別は「男／女」か「1／2」か） |
| (6) | 空欄（該当なし・未取得）の表し方 |
| (7) | 1 ファイルに 1 名か、複数名をまとめるか |
| (8) | ファイル名の規則 |

また、**ALA のご摂取日時／採尿日時／排尿回数／検体の冷凍保存／採尿前日のお薬・ご飲酒**の各項目につきまして、現在の弊社の問診にはご設問がなく、どこで取得するのが適切か決めかねております。**① 必須か任意か　② いつ時点の情報か　③ 弊社側で取得すべきか、貴社の検体受付でご取得いただいているか**をご教示いただけますでしょうか。

## 5. 検査結果PDF のご提出について

ご提出は、同じポータルの「検査結果PDFを提出」からお願いいたします（ドラッグ＆ドロップ・**1 ファイル最大 50MB**）。**パスキーをご登録いただいた端末から、そのまま弊社へお送りいただけます。**

**ファイル名にバーコードNo. を含めていただけますと、検体との突合が確実になります。** 貴社で現在お使いのファイル名の規則をご教示ください。
