### 2.2 ウェルネス年齢は今回付かない (実測で確定 2026-09-15)

**10 名とも算出できない。** 理由が 2 つ独立に成立する。

| # | 理由 | 根拠 |
|---|---|---|
| 1 | **必須項目が検査票に無い** | ①正規版 CABA v5.4 の必須 = `albumin` `creatinine` `glucose` `lymph` `mcv` `alp` `wbc` (`health-age.ts:74-76`) / ②簡易版 v7.0 の必須 = `albumin` `creatinine` + (`glucose` または `hba1c`) (`health-age-simple.ts:139-147`)。**どちらもアルブミンとクレアチニンが要る** |
| 2 | **V4 の 1 クリックは算出を呼んでいない** | `HealthAgeData` を作るのは `elith-assemble` で、`diagnosis.health_age_scores` に保存済みのスコアを `source_ref` で突合して生成する (`elith-assemble.ts:273,534`)。`elith-hc-merge` は作らない (health-age の参照 0 件) |

**実物で確認した項目構成** (どちらもアルブミン・クレアチニンの**欄自体が無い**):

- **健診 A (5 名・スキャン画像)** = 「健康診断個人票（法定）」。血液型 / 白血球数 / 赤血球数 /
  血色素量 / ヘマトクリット / 血小板数 / AST / ALT / γ-GTP / 尿酸 / 総コレステロール / HDL /
  トリグリセライド / LDL / 血糖 / HbA1c / 赤沈 / 尿糖 / 尿蛋白 / ウロビリノーゲン / 潜血 /
  便潜血。**「その他の検査」欄は空**。
- **健診 B (5 名・`その他（氏名）.xlsx` 39 列)** = 生活習慣病健診（定期健診）。§15.1 の 28 項目。

→ **③算出不能**。定型文 `WELLNESS_AGE_UNAVAILABLE_MESSAGE` の対象。**値を作らない (捏造ゼロ)。**

**直す話ではなくデータの話。** アルブミンとクレアチニンは血液検査（デメカル）側の項目なので、
**血液検査を実施した回からは付く**。今回の ZIP に血液検査は含まれていない。

**Elith への申し送りは訂正済み** — 「付与できない方が出る可能性」→「今回は付きません」。
